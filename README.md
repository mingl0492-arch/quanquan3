# 权权目标管理 · 快速便携文件夹版（真正修复添加目标）

这是修复“无法添加目标”后的版本。上一版的弹窗 DOM 位于脚本之后，导致应用初始化时找不到弹窗按钮，添加功能无法绑定。本版已修复，并保留直接上传 `release/win-unpacked` 便携文件夹的稳定打包方式。

## 这版修复了什么

- 修复 GitHub Actions 中 `package-portable.ps1` 的字符串解析错误。
- 保留“快速便携文件夹版”，不做单文件自解压 EXE，因此启动更快。
- 添加目标使用应用内部弹窗，避免 Electron 里 `prompt` 不稳定。
- 默认目标树只有一个：`起点目标`。
- 去掉重置功能。
- 去掉删除节点统计。
- 同级目标块距离加大，避免挨得太近。
- 数据和缓存都在软件目录旁边，适合 U 盘携带。


## 添加目标说明

这一版为了彻底避免 Electron 弹窗兼容问题，已经把“添加目标”改成最稳定的方式：

1. 先点击一个目标块。
2. 点击顶部“添加目标”。
3. 系统会立刻创建一个默认名称为“新目标”的次级目标。
4. 新目标会自动选中，右侧详情栏会自动聚焦文字编辑框，直接改名即可。

这样不依赖浏览器 prompt，也不依赖额外弹窗，添加目标块会更稳定。

请复制整个解压后的文件夹，不要只复制 `权权目标管理.exe`。

推荐结构：

```text
权权目标管理便携文件夹版/
├─ 权权目标管理.exe
├─ resources/
├─ locales/
└─ 权权目标管理数据/
```

以后用 U 盘在不同电脑切换时，直接复制或携带整个文件夹即可。

## 如果网页上传漏掉 .github

如果上传后 Actions 页面没有出现工作流，说明 `.github` 隐藏目录没传上去。

解决方法：

1. 在 GitHub 仓库 Code 页面点击 **Add file → Create new file**。
2. 文件名填写：

```text
.github/workflows/build-windows.yml
```

3. 内容复制根目录这个文件：

```text
GITHUB_ACTIONS_WORKFLOW_网页上传备用.yml
```

4. Commit changes。
5. 回到 Actions 页面运行工作流。

## 本版对“无法添加目标”的最终排查结论

如果点击按钮没有任何反应，说明不是目标树布局问题，而是按钮点击事件没有成功执行，或者旧缓存数据结构异常导致执行中断。

本版做了三层修复：

1. 给“添加目标”按钮增加原生 `onclick` 兜底。
2. 增加 document 级事件委托，即使普通监听失败也能捕获点击。
3. 每次添加前自动修复旧缓存数据结构，避免旧数据导致添加函数中断。

添加成功后会出现顶部提示：“已添加新目标，可在右侧改名”。

## 本次真正修复的根因

上一版仍然无法添加，是因为按钮里写了：

```html
onclick="window.addGoalFromButton && window.addGoalFromButton(event)"
```

但代码里没有真正生成 `window.addGoalFromButton` 这个函数。  
所以点击按钮时，函数是 `undefined`，添加逻辑完全没有执行。

本版已经真正加入：

```js
window.addGoalFromButton = function(event) {
  addGoalDirect();
}
```

因此点击“添加目标”会实际执行添加函数。添加成功后会出现顶部提示，并自动选中新目标。


## v1.4.0 关键修复

这版不再继续修补旧的内联脚本，而是把页面逻辑拆成独立的 `app/renderer.js`。

之前从截图判断，页面脚本没有完整执行：画布没有渲染起点目标，进度统计停留在静态 0，因此点击“添加目标”之前，渲染层已经中断。

v1.4.0 已经重写：

- 目标树渲染
- 添加目标
- 删除目标
- 状态切换
- 进度统计
- 右侧文字编辑
- 鼠标滚轮缩放
- 画布拖拽

点击“添加目标”会直接生成“新目标”，并自动选中，右侧可立即改名。


## v1.5.0 多目标条目版

本版基于 v1.4.0 外置渲染版继续修改，新增“目标条目”功能，其他目标树功能保持不变。

新增功能：

- 左侧新增“目标条目”模块。
- 可以新增目标条目。
- 可以删除当前目标条目。
- 一个目标条目对应一套独立的：
  - 目标进度总览
  - 目标块树
  - 目标状态
  - 右侧详情编辑
- 切换目标条目后，进度条和目标树会同步切换。
- 修改一级目标名称时，目标条目的名称也会同步更新，方便识别。
- 旧版单目标数据会自动迁移为第一个目标条目。
